## 它解决什么问题

| 原本 | 现在 |
| --- | --- |
| 门户流程列表一次只能看一页、要手动翻 | 一键读取前 N 页 / 按发起日期读取 |
| 待办要逐单点进详情、点打印、点确定 | 一键出「寄件申请信息单」，直接打印 |
| 快件查询结果要人工抄到 Excel | 导出 `飞鸿清单YYYYMMDD.xlsx`（两张表：发车清单 / 完整数据） |
| 改物流状态要在原站表单里逐项填 | 工作台内置调整单填写与提交（提交前确认，提交后不回读） |
| 待办要逐单「批量处理 → 通过」 | 勾选后一键批量通过 / 退回，自动刷新列表 |

## 安装（推荐：下载 Release 发布包）

1. 打开本仓库右侧 **Releases**（或直接访问 [v0.9.194](https://github.com/bitbravery/jinggong-feihong/releases/tag/v0.9.194)），下载发布包 `jinggong-feihong-v0.9.194.zip`；
2. 解压到**固定目录**，例如 `D:\京工飞鸿\`（升级要保持同一路径）；
   - 确认解压后该目录里**直接**能看到 `manifest.json`；如果多套了一层文件夹，加载时选到里面那一层；
   - 目录里不能有以 `_` 开头的文件，否则 Edge 会拒绝加载。
3. 地址栏输入 `edge://extensions` → 打开「开发人员模式」→「加载解压缩的扩展」→ 选择该目录；
4. 打开学校门户 `https://ehall.bit.edu.cn`，打开「京工飞鸿两校快件系统」标签，点工具栏红色飞鸿图标；
5. 左下角显示 `接入版 v0.9.194 · 提交核验版` 即安装成功；
6. 换电脑：旧机器「楼宇与区域 → 导出设置」，新机器「导入设置」。

> 没有 Releases 时也可以走源码：点 **Code → Download ZIP**，解压后按上面第 3 步加载（需自己确认版本号）。

图文步骤见 [`docs/使用教程.pdf`](docs/使用教程.pdf)，清单版见 [`docs/部署清单.md`](docs/部署清单.md)。

## 使用要点

- **流程办理**：先在门户把「流程」页打开，工作台里选「待办 / 已办」，点「读取当前页」或「读取前 N 页」；要按时间筛选，先设起止日期再点「读取日期段」。
- **待办 ≠ 已办**：待办里的单**不能改物流状态**，要先「批量处理 → 通过」变成已办，才可调整。
- **打印申请单**：不跳原站，扩展内直接渲染「寄件申请信息单」（A4 横向），可打印或存 PDF。
- **导出**：文件名 `飞鸿清单YYYYMMDD.xlsx`，同一天重复导出自动加 `(1)(2)`。
- **批量改状态**：一单一单串行执行，每单都核对单号、联系人、当前状态；对不上立即停。

## 权限与安全

- 仅申请 `activeTab / scripting / storage`，**不申请任何站点权限**，不发起任何网络请求（CSP `connect-src 'none'`）；
- 全部操作通过 `chrome.scripting.executeScript` 注入到**你当前打开的门户页面**执行，等同于你本人在页面上点击；
- 数据只存本机浏览器（`localStorage` + `chrome.storage.local`），不上传第三方。

## 仓库结构

```

worker.js              后台编排（注入、等待、状态机）

```

## 开发

```powershell
# 在仓库根目录运行全部检查
Get-ChildItem tests -Filter *.cjs | ForEach-Object { & node $_.FullName; if ($LASTEXITCODE -ne 0) { "FAIL: $($_.Name)" } }
```

必须全部通过（0.9.194 时共 65 个）。版本号需同时改 4 处（`manifest.json`、`worker.js`、`live.js`、`index.html`），`tests/版本一致性检查.cjs` 会校验。

## 已知限制

1. 打印页由扩展自绘（与门户表单同字段、同版式），不是门户原页；
2. 流程分类自动切换依赖门户标签样式，门户改版后需同步调整；
3. 批量通过/退回属写操作，首次使用请先用 1 单验证；
4. 提交结果以“看到提交成功”或“调整单标签自动关闭”为准，不做二次回读。

兼容性：Edge 120+（Chromium 内核 MV3）；未在 Chrome / Firefox 上测试。
