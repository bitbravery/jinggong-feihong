# 办公电脑部署清单（v1.0.5）

> 当前版本 v1.0.5（首个正式版：读取/流程批量处理、已办实际状态回查、批量改状态（可随时取消）、改回原状态、打印申请单、导出 Excel、状态修改历史（精确/快速查看原站状态）、重要提示）。
> 按顺序做，全程约 10 分钟。每台办公电脑只需做一次。

## 一、准备

- [ ] 拿到 `jinggong-feihong-v1.0.5.zip`
      （SHA256 `399C97C396722A41233AAE760D06C8B9E83641D5B5372C08485BB07689B0A52B`，可先用 `certutil -hashfile 文件名 SHA256` 核对；解压后先按第五节自检版本号 v1.0.5）
- [ ] 解压到**固定目录**，例如 `D:\京工飞鸿\`（不要放桌面、下载文件夹或临时目录，以后升级要保持同一路径）
- [ ] 确认解压后的目录里**直接**能看到 `manifest.json`、`worker.js`、`source.js`
      （如果多套了一层同名文件夹，加载时选到里面有 `manifest.json` 的那一层）
- [ ] 确认目录里**没有**任何以 `_` 开头的文件或文件夹。
      Edge 会直接拒绝加载并报 “Filenames starting with "_" are reserved”，这不是版本问题。
- [ ] 确认用的是 **Microsoft Edge**（Chrome 未测试）

## 二、安装扩展

1. 地址栏输入 `edge://extensions` 回车
2. 打开 **开发人员模式**
3. 点 **加载解压缩的扩展**，选择刚解压的目录（能看到 `manifest.json` 的那一层）
4. 扩展列表里出现「京工飞鸿」即成功；建议点扩展图标 → 固定到工具栏，之后好找

## 三、首次连接与配置

1. 新标签打开学校门户：`https://ehall.bit.edu.cn`，登录
2. 在原站打开「京工飞鸿两校快件系统」标签（工作台靠这个标签工作，**使用期间不要关掉它**）
3. 点工具栏**红色飞鸿图标**，工作台在新标签打开
4. 左下应显示 `接入版 v1.0.5 · 提交核验版`
5. 选择当前窗口校区（良乡 / 中关村）——这决定「楼宇与区域」用哪套映射
6. 「楼宇与区域」里按本单位实际情况核对/补充楼宇与区域对应关系（这是唯一需要人工配置的部分）

## 四、迁移数据（换电脑才需要）

- 旧电脑：工作台 →「楼宇与区域」→ **导出设置**，得到 `飞鸿设置-xxx.json`，拷到新电脑
- 新电脑：同一页面 → **导入设置**，选择该文件

> 注意：解压路径不同，扩展 ID 会变，旧数据不会自动跟过来，必须走导出/导入。
> 所以所有电脑尽量用**同一个解压路径**（例如都用 `D:\京工飞鸿\`）。

## 五、自检（6 项，逐条打勾）

- [ ] 工作台左下版本号是 `v1.0.5`
- [ ] 「快件查询及状态调整」→「读取当前页」能读到数据（状态栏显示行数）
- [ ] 「流程办理」→ 选「待办」→「读取当前页」能读到数据
- [ ] 任意一行点「打印申请单」→ 弹出「寄件申请信息单」→ 点「打印」出现打印预览
- [ ] 「导出 Excel」得到 `飞鸿清单YYYYMMDD.xlsx`，能正常打开
- [ ] **改一单真实物流状态**：弹窗里提示会自己走秒（`正在核对原站…（N 秒）`），
      原站出现「提示信息 / 您确定要提交吗？」后自动关闭，最后提示「已提交」，历史里显示「已确认提交」；批量过程中「取消」随时可用

## 六、给同事的四条使用提醒

1. **待办里的单不能直接改物流状态**：先在原站「批量处理 → 通过」变成已办；
2. 读取大列表（已办上万条）用「读取前 N 页」，别一次读太多；
3. 提交物流状态后**不会自动回读**，要核对就点「查看原站状态」；
4. 若提示「原站表单里某单的当前状态是「A」，工作台记录的是「B」」，说明两边不一致：
   原站变了就点「读取当前页」同步；原站表单还是旧的就关掉那张「物流状态调整单」标签重试。

## 七、升级到新版本

1. 把新包解压到**同一个目录**，覆盖旧文件（先关掉工作台标签更稳）
2. `edge://extensions` → 找到「京工飞鸿」→ 点卡片上的**刷新/重新加载**图标
3. 回门户点红色图标重新连接，确认左下版本号已变

> 只刷新工作台页面**不会**更新后台，必须点扩展卡片上的刷新。
> 升级后如果提示「后台版本不匹配」，就是第 2 步没做。

## 八、常见问题

| 现象 | 处理 |
| --- | --- |
| 加载时提示文件名以 `_` 开头 | 目录里有 `_` 开头的文件，删掉后再加载 |
| 加载后扩展列表没有出现 | 选错层级，要选到含 `manifest.json` 的那一层 |
| 点图标没反应 / 提示未连接 | 回到门户页面再点图标；确认扩展已启用 |
| 读取提示「请按安装说明加载扩展」 | 在文件预览里打开了 HTML，需从门户点图标进入 |
| 提示「后台组件仍是旧版本」 | 在 `edge://extensions` 点扩展刷新，再回门户点图标 |
| 打印预览里没有内容 | 确认点的是行内「打印申请单」，不是浏览器菜单里的打印 |
| 提交卡在「已点击“确定”但弹窗未关闭」超过 60 秒 | 记下提示里的诊断发回；不要重复提交，先用「查看原站状态」回读 |

## 九、合规提醒

本扩展只读取你本来就能看到的页面内容、只执行你本人可执行的操作，但**仍建议先向单位信息化/保密管理部门报备**后再在办公电脑使用；不要在公共电脑上保存登录态。
