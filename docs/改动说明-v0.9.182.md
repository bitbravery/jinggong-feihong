## 2. 换行统一为 LF
- 原来 Git 里存的是 LF，但工作区有 24 个文件是 CRLF、13 个混用，按原文定位的修改脚本会因此漏改。
- 新增 `.gitattributes`（`* text=auto eol=lf`，图标按二进制），把工作区 37 个文件转成 LF；本仓库 `core.autocrlf` 设为 false。
- Git 内容除 README 外没有任何变化（`git diff` 只显示 README）。
- 新增 `换行检查.cjs`：扩展目录里的 js/cjs/html/css/json/md 含 CRLF 即失败（已用临时 CRLF 文件验证会报错）。
