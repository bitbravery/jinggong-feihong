# 怎么向同学介绍「京工飞鸿」工作台

> 用途：班前会、交接培训、给新同事做 10 分钟讲解。
> 原则：**先讲他们每天受的累，再演示一屏解决；技术细节留到提问环节。**

---

## 0. 一句话版本（电梯陈述，15 秒）

> “我们在门户外面套了一个工作台：查件、看流程、打印申请单、改物流状态，原来要在四五个标签页之间来回点，现在一屏做完，重复的点击它替我们点。”

如果对方只记得一句：**“它不替代门户，它替我们点。”**

---

## 1. 开场：先让对方点头（1 分钟）

不要一上来讲扩展，先讲他们昨天做过的事：

> “昨天派件，你在门户里查一单，是不是得先把「单号」那一列拉宽才能看全？
> 待办里要改状态，是不是得先「批量处理 → 通过」，再打开办理入口、粘贴单号、点空白等它联动、选状态、提交、再点确定？
> 一单两分钟，十单半小时，还容易点错。”

停两秒，等他们点头。然后：

> “这些动作有一个共同点：**每次都一样，只是单号不同**。那就该让机器做。”

---

## 2. 它到底做了什么（2 分钟，配图 2）

打开工作台，只指四个地方，不要讲代码：

| 指哪里 | 说什么 |
| --- | --- |
| 左侧四个菜单 | “流程、查件、楼宇、历史，就这四块。” |
| 右上读取条 | “读当前页、读近一月、按日期段读，点一下就行。” |
| 表格行内 | “每行三个动作：打印申请单、改物流状态、详情。” |
| 底部批量条 | “勾几单，批量改状态，它一单一单替你做。” |

然后一句总结：

> “**读、看、打、改**，四件事都在这一屏。”

---

## 3. 现场演示（5 分钟，按这个顺序）

演示前准备：门户已登录，「京工飞鸿两校快件系统」标签已打开，工作台已连上，选好测试单。

### 3.1 读（40 秒）
- 点「读取当前页」→ 指状态栏：“读到 30 行，用时 X 秒。”
- 点「近一个月」→ “不用手填日期，它自己设条件。”

### 3.2 筛 + 打印（60 秒）
- 搜索框输一个姓名 → “筛出来就这几单。”
- 点行内「打印申请单」→ 弹窗出来 → **先别点打印**，说：“A4 横向，字段和原站一模一样，不跳标签、不用二次确认。”
- 点「打印」→ 预览出现 → 关掉。

### 3.3 批量通过（60 秒）
- 切「流程办理」→「待办」→「读取当前页」
- 勾 1 单 → 底部「批量通过」→ 确认 → “它自己去勾选、点批量处理、点通过、点确定。”
- 完成后指列表：“这单已经从待办消失了。”

### 3.4 改一单物流状态（90 秒，重点）
- 回「快件查询及状态调整」，选一单 →「改物流状态」→ 选目标状态 →「提交修改」
- 让它自己跑，边跑边说三句：
  1. “它会先把单号填进去，等原站联动出寄件人、地址。”
  2. “**核对三件事**：单号一致、联系人出来了、当前状态和我看到的一样——不一样它会停，绝不硬改。”
  3. “提交后它自己点「确定」，只认两种成功信号：看到「提交成功」，或者调整单标签自己关了。”
- 完成后指历史：“结果和依据都记在这儿，包括用时。”

### 3.5 导出（30 秒）
- 点「导出 Excel」→ “文件名自动带日期，两张表：发车清单、完整数据。”

### 3.6 收尾一句（15 秒）
> “刚才这些，手工大约 8 分钟；现在 3 分钟，而且每一步都有记录。”

---

## 4. 必须主动说的三件事（1 分钟）

主动说，比被问出来强：

1. **它不绕开原站**：登录、权限、数据都还是门户那一套，它只是替你点按钮。
2. **它会停**：单号对不上、状态不一致、出现重复单号，它宁可停下也不改。
3. **结果不明时不要重复提交**：它会明确写“结果不明，禁止自动重试”，先到原站核对。

---

## 5. 常见提问与回答

| 提问 | 回答 |
| --- | --- |
| 数据会不会传到网上？ | 不会。扩展只申请三个本地权限，没有任何外部网络请求，数据只在本机浏览器里。 |
| 会不会改错单？ | 改之前核对三项：单号、联系人、当前状态；任何一项不符立即停。重复单号直接禁止修改。 |
| 门户改版了怎么办？ | 会失效，需要维护。工作台有「诊断」按钮，能把现场结构导出来定位。 |
| 换电脑怎么带走配置？ | 「楼宇与区域」里有导出/导入设置，一个 json 文件。 |
| 为什么不做成网页/小程序？ | 那要拿账号密码或会话，合规上过不去；扩展用的是你已登录的页面。 |
| 能不能给我也装一个？ | 可以，同一个压缩包、同一个解压路径（例如 `D:\京工飞鸿\`），装完自检五项。 |
| 速度快吗？ | 读取基本是秒级；改状态每单要等原站建表单、联动，比手工快但取决于原站。 |
| 出了问题找谁？ | 找维护人，把「诊断」输出和提示原文发过去。 |

---

## 6. 不要说的话

- ❌ “全自动，不用管了” → 实际仍需人核对异常。
- ❌ “比原站快十倍” → 原站响应不可控，别给数字承诺。
- ❌ “替代门户” → 它是外挂工具，门户照常可用。
- ❌ “绝对不会出错” → 应该说“出错会停，不会乱改”。

---

## 7. 30 秒极简版（时间被压缩时）

> “原来查件、打印、改状态要开四五个标签来回点；现在一个工作台，读、看、打、改都在这屏。
> 它不替代门户，只是替我们点按钮，点之前会核对单号、联系人和状态；对不上就停。
> 数据不出本机。压缩包拷过去，解压、加载扩展、点图标就能用，五分钟。”
